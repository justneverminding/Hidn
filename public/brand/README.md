# HIDN brand assets

This directory is the canonical location for supplied HIDN brand assets.

The supplied approved reference artwork is stored unchanged at:

- `references/hidn-brand-reference-01.png`
- `references/hidn-brand-reference-02.png`

The public shell uses two approved crop-only navigation derivatives, created
with explicit approval from the logo lockup in reference 02:

- `hidn-logo.png` — full desktop logo crop, 390×124 RGB PNG;
- `hidn-symbol.png` — square mobile eye-symbol crop, 124×124 RGB PNG.

The source reference artwork remains unchanged. These derivatives are not
redrawn, recolored, stylized, transparentized, or destructively compressed.
The crop coordinates and source-of-truth rules are documented in
`docs/HIDN-BRAND.md`.

The eye symbol is canonical: it communicates presence without exposure.
