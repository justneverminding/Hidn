# HIDN brand assets

The HIDN logo is the prompt mark `>hidn▌`. The files here are generated by
`marketing/tools/render-logo-final.swift`; see `docs/HIDN-BRAND.md` for the
rules.

- `hidn-mark.png` — 1024×1024 master;
- `hidn-icon-512.png`, `hidn-icon-192.png` — app and manifest icons;
- `hidn-apple-touch-icon.png` — 180×180 home-screen icon;
- `hidn-favicon-64.png`, `hidn-favicon-32.png` — browser tab icons;
- `hidn-wordmark.png` — transparent header wordmark;
- `hidn-og-terminal.png` — link-preview image;
- `hidn-museum-gallery.png`, `hidn-museum-panorama.png` — museum imagery.

`references/` keeps the original supplied artwork unchanged, as mood and
texture references. The eye logo in it is retired as the HIDN logo.
